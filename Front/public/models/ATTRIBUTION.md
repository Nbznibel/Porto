# Model attribution

The active character is a procedural low-poly fantasy knight built from Three.js primitives in `src/features/characterdesign/components/CharacterModel.tsx`. It does not load an external model file.

`hero.glb` is retained for historical reference only and is no longer used by the app. It is the **RiggedFigure** model from the Khronos glTF Sample Assets repository.
